# Setup Guide

This guide explains how to set up two devices to work together: one acting as the **Camera** to capture video, and the other as the **Remote** to control it.

---

## 📷 Camera Setup
*Use the device you want to use for capturing and recording video.*

1. **Sign In**: Log in using your **Apple** or **Google** account.
2. **Initialize**: Start the Camera mode and wait for the pairing request.

---

## 📱 Remote Setup
*Use the second device to preview and control the Camera.*

1. **Choose Pairing Method**: Select your preferred connection method:
   * **Account**: Pair automatically using the same Apple or Google account.
   * **QR Code**: Scan the QR code displayed on the Camera device.
2. **Connect**: Select the target **Camera** from the list to start pairing.
